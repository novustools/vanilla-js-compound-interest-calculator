# Vanilla JS Compound Interest Calculator Logic

This repository contains the core, dependency-free JavaScript math logic for calculating complex compound interest scenarios. 

Built for financial developers who need to calculate advanced investment metrics, including inflation-adjusted real returns, annual contribution step-ups, and milestone tracking (e.g., first $100k or $1M), without external libraries.

For the full, interactive enterprise tool with visual charts, advanced reporting, and custom print layouts, visit the [NovusTools Compound Interest Calculator](https://novustools.com/compound-interest-calculator/).
